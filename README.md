# Stockify 🚀

A full-stack stock trading platform inspired by Zerodha, built using the MERN stack.

## Features

* User Authentication with JWT
* Google OAuth Login using Firebase
* Buy/Sell Stock Window
* Holdings & Positions Tracking
* Orders Management
* Interactive Dashboard UI
* REST API Integration
* Context API State Management
* Responsive Landing Page

## Tech Stack

### Frontend

* React.js
* React Router DOM
* Axios
* Firebase Authentication
* Bootstrap / CSS

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose
* JWT Authentication

## Project Structure

* `frontend` → Landing page + authentication
* `dashboard` → Trading dashboard UI
* `backend` → Trading APIs
* `server` → Authentication server
